## 五、如何使用

- **A 类**：写入设计检查表，作为五星目标下的硬性要求。
- **B 类**：不作为差异化设计的着力点，但缺失会直接掉星，属于必保项。
- **C 类**：这些细项才需要预测模型。若模型在 C 类上不优于平凡基线，
  说明当前可观测输入不足以支撑该项预测——这本身是可报告的结论。


## 六、一处必须声明的方法学差异

**配置准则与细项准则的可信度不同：**

| | 循环性 | 说明 |
|---|---|---|
| 配置准则 | **无** | 气囊、安全带等配置不直接进入总分公式（加分项除外），
「五星车装配率高」与「星级由得分决定」之间没有恒等关系，判别力是干净的 |
| 细项准则 | **有** | 星级由各细项得分加总而来，「五星车某项满分率高」部分是同义反复。
判别力仍有意义（它说明该项**相对其他项**更能区分），但不可解读为因果 |

改进方向：在总分相近的车辆之间做配对比较，以剥离总分效应。此为后续工作，
当前版本未做，相关结论须按上述限定表述。
